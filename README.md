# MarketBoost — Digital Marketing Dashboard

A responsive digital marketing portfolio project built with **HTML and CSS**. It presents a sample campaign report with performance metrics, traffic sources, campaign status, and marketing service cards.

## Features
- Responsive layout for desktop, tablet, and mobile
- Marketing KPI cards for impressions, clicks, leads, and ad spend
- Campaign performance table
- Traffic-source donut chart made with CSS
- Audience growth line chart using inline SVG
- SEO, paid ads, social media, and email marketing sections
- No build tools or dependencies required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Upload to GitHub
1. Sign in at [GitHub](https://github.com/) and create a new repository, for example `digital-marketing-dashboard`.
2. Upload `index.html`, `style.css`, and `README.md` (or push them with Git).
3. To publish it as a live website, open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in the Pages settings.
